# Project 4 — pipeline status

This folder holds the outputs of the R pipeline. Runs are kept in
separate subfolders so pilot snapshots stay frozen while the panel
evolves.

```
results/
├── pilot_10genes/      # frozen 10-gene pilot
└── ped_gof_snv/        # current 24-gene SNV/indel GoF panel; regenerated by 01..07
```

The active run is controlled by the `RUN_NAME` constant near the top
of each `R/0X_*.R` script (currently `"ped_gof_snv"`). To freeze
another run, point `RUN_NAME` at a new subfolder before re-running.

**Legacy note:** An older **42-gene** SJPedPanel-derived run used
`results/all_42genes/` (not always present in the tree; see git history
or rebuild from `oncogene_shortlist_sjpedpanel.tsv`).

## Pipeline

1. `00_build_target_genes.R` — fetch GRCh38 coords for all genes in
   the active shortlist (default `data/oncogene_shortlist_ped_gof_snvs.tsv`,
   24 genes) from Ensembl REST; write `data/target_genes.tsv` (single
   source of truth for 01..07). Legacy: `oncogene_shortlist_sjpedpanel.tsv`
   (42 genes).
2. `01_profile_inputs.R` — sanity-checks all three input files.
3. `02_inspect_vaf.R` — explores VAF; counts markers in target loci.
4. `03_annotate_variants.R` — submits all coding variants in target
   loci to **Ensembl VEP REST API (GRCh38)**; restricts to MANE Select
   / canonical transcripts; emits `HugoSymbol`, `HGVSp_Short`,
   `Variant_Class`. Normalises HGNC renames (e.g. `H3-3A` → `H3F3A`).
5. `04_hotspot_summary.R` — recurrence summary per gene; loads
   `data/hotspots_tier0.csv` for the (gene, codon) lookup.
6. `05_apply_hotspot_tiers.R` — joins the curated Tier-0 hotspot file
   `data/hotspots_tier0.csv` and assigns `Mut_Status`
   (`Hotspot / Missense_Other / InframeIndel / Truncating / Silent`).
7. `06_link_to_depmap.R` — joins DepMap ACH IDs via `samples.txt`.
8. `07_waterfall_plots.R` — waterfall PDFs grouped by tier.

### Outputs (per run; same filenames under `pilot_10genes/`, `ped_gof_snv/`, etc.)

- `03_vaf_annotated.tsv` — every coding variant in the target genes
  with VEP annotation.
- `04_recurrent_missense_per_gene.tsv` — per-gene counts of recurrent
  protein changes (useful for sanity-checking & for curating Tier-0).
- `05_mutations_tiered.tsv` — **the file to use for the waterfall
  plot.** One row per `(PID, gene_symbol)` carrying a
  hotspot/missense/inframe/truncating event.
- `07_waterfalls_pancancer.pdf`, `07_waterfalls_facet_lineage.pdf` —
  per-gene CRISPR Chronos waterfall plots, with gene title prefixed by
  the tier label.
- `07_effect_sizes.tsv` — per-gene median(Hotspot) − median(WT) and
  median(any-mut) − median(WT) deltas.

## Open questions

### 1. Patient ↔ cell-line linkage (the big one)

`AllMarkers_VAF_long.tsv` is keyed by St. Jude tumor patient IDs
(`SJST*`, `SJOS*`, `SJNBL*`, …). Step 06 joins to DepMap ACH IDs via
`samples.txt`; overlap counts depend on the gene panel and cohort
(e.g. the legacy 42-gene run added genes such as DDX3X, CTCF, MYC,
PPM1D, H3F3A to the join vs the 10-gene pilot).

### 2. ERBB2 hotspot list looks short (pilot only)

Only 6 / 19 ERBB2 missense PIDs hit a Tier-0 codon. Worth checking
whether we should add ERBB2 R678Q (recurrent in our data, 2 PIDs)
and any kinase-domain residues from the recent ERBB2 hotspot
literature. ERBB2 is *not* in the 24-gene SNV panel (or the legacy
42-gene solid/brain-filtered set) but is preserved in the pilot.

### 3. PPM1D last-exon truncations are GoF, not LoF

VEP labels them `Frameshift`/`Nonsense`, so step 05 currently puts
them in `Truncating`. Biologically those should join the `Hotspot`
bucket. Quick fix: in `R/05_apply_hotspot_tiers.R`, special-case
PPM1D + `Truncating` + codon ≥ 420 → `Hotspot`.

### 4. Fusion-only Tier B / C genes

`AllMarkers_VAF_long.tsv` is SNV/InDel/MNV-only, so in the **legacy**
42-gene panel, Tier-B genes like
`EWSR1`, `ZFTA`, `NTRK3`, `FOXO1` (partner) and most of Tier C
(`KIAA1549, SS18, TFE3, ASPSCR1, USP6, COL1A1`) get empty waterfalls.
The current **24-gene** panel omits most fusion-only drivers by design.
To get signal on fusion-listed genes, layer in
DepMap's `OmicsFusions.csv` join into `06_link_to_depmap.R`.

### 5. AlphaMissense layer

Not yet integrated. Once 1 is resolved we can layer
`AlphaMissense_aa_substitutions.tsv.gz` onto the
`(transcript_id, protein_start, aa_alt)` key in
`results/<run>/03_vaf_annotated.tsv`. Then we'll have the AM tier
alongside the Tier-0 tier and can do the AM-evaluation analysis.
